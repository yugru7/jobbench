本项目做了一些爬取安全措施（拟人操作、随机节奏、限额与只填不发），但用自动化工具操作账号仍然有被封号的风险。如果介意，请不要使用。

这个项目是什么

Job Search Workbench（求职助手）是一个 本地运行 的 BOSS直聘 自动化工作台：它在你这台电脑上跑，只监听本机（127.0.0.1），配置与知识库都留在本地、不上传到任何地方。它帮你批量爬取岗位、读取 JD 与招聘者活跃度、按你的知识库生成逐条定制的招呼语，最后由 你亲自确认发送。

它不是无人值守的群发器：默认「只填不发」，所有发出去的消息都经过你的把关

配置、知识库、候选池、打招呼记录全部是项目目录里的明文文件，随时可查、可改、可删

它能做什么（六步链路）

1 备好知识库：填「我是谁 / 我的经历 / 我的技能」，也可让 agent 访谈式帮你补全；它是招呼语取材的唯一来源

2 岗位初筛：来源（搜索 / 推荐 / 意向方向 / 收藏）、城市、单次数量；搜索模式下填投递关键词

3 爬岗位：自动逐个打开岗位页，读出 JD、薪资、招聘者活跃度、公司规模与行业，进候选池

4 二次筛选：按活跃度 / 双休 / 日薪 / 行业过滤，勾选要投的；也可让 agent 智能勾选

5 写招呼语：勾选岗位逐条生成定制版（对准这条 JD，不是群发模板），可手改，自动保存

6 发送：默认「放到输入框」填好就停，你在浏览器里过目后自己点发送；全过程留痕到「记录」

哪里需要 agent，agent 能做什么

机械活工具自己干，判断活交给 agent；两者分工明确，你随时能接管。

工具自己干（机械部分）：浏览器操控、爬取解析、招呼语填入、记录留痕、安全护栏

agent 来干（智能部分）：评判岗位与你简历的匹配度并自动勾选、按 JD 逐条写定制招呼语、通过访谈帮你补全知识库、按你的情况调爬取数量与节奏

agent 通过本地 HTTP 接口操作本工具，每一步都在面板上实时可见；操作手册见项目根目录 AGENTS.md，把它交给你的 AI 助手即可

agent 无权替你自动发送：接口层面只允许「只填不发」或「逐条等你确认」；全自动发送必须你本人在面板上亲自批准

账号安全性防护

来源层：面板与接口只受理来自本机的请求（Host / Origin 白名单，只认 127.0.0.1 / localhost）。恶意网页打不开你的接口，伪装域名（DNS 重绑定）也读不到你的知识库、清不掉你的候选池；命令行与 agent 正常调用不受影响

驱动层：用 Patchright（Playwright 的反检测分支），不产生 CDP 自动化痕迹；跑的是你自己的 Chrome 配置目录，指纹与登录态都是真实的

行为层：点击带鼠标轨迹与随机落点（含真实按压时长）、滚动有速度包络与微动、招呼语分块粘贴模拟人工输入、看岗位有停顿（默认停留 1~2 秒、滚轮滑动 300~700 像素）、岗位间隔随机：爬取默认 4~7 秒（约 25% 概率进入 7~11 秒的「偶尔慢一点」）、发送默认 4~6 秒（约 25% 概率进入 6~12 秒）

预热：全新启动浏览器时，任务开头会随机打开一个常见网站（百度 / 必应 里随机选一个）停留一两秒，再进 BOSS。既让首页渲染完整（不预热容易只加载出一两张卡片），也避免「直奔目标站」这种脚本特征；浏览器已是热的（复用来的）则直接跳过预热

限额层：每日发送上限（默认 60）、每日爬取上限（默认 80）、单次爬取上限（少量多次，服务端硬顶 30）；发送时按当日剩余额度自动截断

流程层：默认「只填不发」；「直接发送」必须你本人在面板上亲自确认；遇到安全验证会停下等你人工完成；反复失败的岗位进黑名单不再触碰

数据放在哪（都在本地）

data/config.json：爬取 / 发送 / 节奏等设置，以及城市

data/knowledge.json：你的知识库（我是谁 / 我的经历 / 我的技能）

data/cities.json / data/filters.json：城市列表 / 岗位初筛筛选项（下拉与筛选条件的数据源）

prompts/greeting.md：招呼语提示词（设置页可改，可一键恢复默认）

logs/last-collect.json：候选池（跨批次累积、按岗位去重）

logs/：运行日志（run-*.log）、记录统计（stats.json）、已打招呼明细（已打招呼记录.txt）、黑名单（黑名单.txt）、勾选副本（checked.json）

界面记忆：筛选条件、勾选、来源 / 发送方式 / 意向方向、当前页签都存在浏览器本地，刷新或重启工具后自动回到上次的样子

使用建议

少量多次：一天多爬几轮、每轮 10 个，比一口气爬 50 个安全得多

宁缺毋滥：先用「放到输入框」人工把关，流程跑顺了再逐步提高自动化比例

先跑顺再放开：爬取数量与节奏都能在「设置」页调，但建议从默认值起，跑顺几轮、没触发风控再逐步加大

正常时段：白天使用；深夜的批量操作在风控眼里最可疑

见好就收：触发安全验证就停下休息，硬跑只会更糟

内容要真：招呼语会发给真人 HR，知识库只写真实做过的事

第一次用

双击 启动.bat，浏览器自动打开面板 http://127.0.0.1:7788；在弹出的浏览器里扫码登录 BOSS，一次即可，之后长期复用（独立配置目录，不影响你日常用的 Chrome）。没有其他安装步骤。

建议首次使用先点顶栏的「打开 BOSS」：它用任务同款浏览器（同一份登录态）打开 BOSS，扫码登录一次即可、之后长期复用；登好再回来点爬取 / 发送，就不会跑到一半被踢回登录页。

面板打不开 = 服务没跑起来，重新双击 启动.bat 即可，不用重装

① 个人经历知识库

三个字段：我是谁（身份 / 学校专业 / 可实习时间 / 到岗情况 / 意向城市，写全，如「计算机相关专业应届生，可实习 6 个月、每周 5 天，能尽快到岗，意向北京」）、我的经历（可写多条，每条写具体：做了什么 / 怎么做 / 什么结果，带数字更好）、我的技能（顿号或逗号分隔，只写真实会的，写全）

它是招呼语质量的根基：细节越多越好，这三个字段没有字数上限，几千字甚至上万字 AI 都读得下；写得越具体，AI 越能挑出「和这条 JD 对得上的点」

可以自己填，也可以让 agent 通过访谈帮你补全；边写边存：改动 0.9 秒后自动写入，离开页面或关闭工具也会立即落盘，不用点保存

只填真实做过的事：招呼语会被 HR 逐字看到，面试可能被追问

② 岗位初筛

来源四选一：搜索（按你填的关键词搜）、推荐（BOSS 给你推的）、意向方向（你在 BOSS 上勾选的求职方向，点「刷新方向」可重新同步）、收藏（你在 BOSS 收藏的岗位，不套城市与筛选）

城市：省份 → 城市两级，全国 373 城；选定立即保存，搜索与推荐都严格按这个城市定位

注意例外：「意向方向」来源跟的是你 BOSS 简历里的期望城市，不受面板城市影响；页签后缀（如「(北京)」）才是实际城市，不对就去 BOSS 改简历期望城市

「收藏」来源拉的是你 BOSS 账号里收藏的岗位，同样不套面板城市、经验与筛选条件（都是你自己挑进收藏的，不再过一遍机器门槛）；这些岗位在列表里岗位名前带「★」并默认勾选（视同已过二筛，agent 不再重判匹配度，但仍会照常写招呼语）

岗位数量：单次爬多少个，默认 10（少量多次）

投递方向：搜索模式下填关键词；一次只爬一个方向（避免跑偏），再加一个会替换掉上一个

③ 获取岗位

点「搜索岗位 / 爬推荐岗位 / 爬意向岗位 / 爬收藏岗位」启动浏览器自动化，逐个打开岗位详情页，自动读出 JD 正文、薪资、招聘者活跃度、公司规模、行业

爬完进候选池：跨批次累积、按岗位去重（重复的不占名额，自动补足目标数量）；加载深度按需——按你要的数量自动决定翻页 / 滚动到哪，够了就停，不把隐藏的岗位一次性全抓完；你改过的招呼语和勾选绝不会被重爬覆盖

候选池里是「爬取那一刻」的快照：BOSS 上这些岗位会实时变动（招满、下架、改要求），本工作台看不到后续变化；建议爬到的岗位尽早发送，别囤太久

任务运行时顶栏显示「运行中」，可随时点「停止」（直接终止，没爬完的就不再爬）

「删除选中」删除前会自动备份到 logs/last-collect.json.bak；就算 agent 在命令行偷偷爬，面板也能检测到并自动并入候选池

④ 二次筛选

筛选器：活跃度（今日活跃 / 3日内活跃 / 本周活跃 / 半年内活跃，选某档即该档及更新）、双休（有 = 每周 ≤5 天，无 = 每周 ≥6 天）、日薪下限（月薪自动折算日薪）、行业关键词

已发送的岗位自动隐藏，不再出现在候选里

勾选：单个点勾 / 按筛选结果全选 / 清空勾选；勾选会被记住，刷新不丢

让 agent 智能二筛：它搜公司背景、按你知识库评岗位匹配度，自动勾上匹配度高的（面板实时可见，不满意直接改成你要的）

筛选条件本身也会被记住，下次打开还是这套

⑤ 编辑招呼语

勾选的岗位逐条成行：岗位 / 公司 / JD（可折叠展开）/ 招呼语

招呼语怎么来，两条路：① 在「二次筛选」勾好岗位后，直接让你的 agent 批量生成，它按「知识库 + 每条 JD」逐条写好；② 也可以自己在表格里手动输入，想写什么写什么

每条都对准各自的岗位：两条调换着还能用就是不合格；agent 写完后你照样能一条条改

改完自动保存：0.9 秒后写入，刷新或切换页面都不丢

招呼语提示词在「设置」页可调（语气、长度、该提什么、避什么）：点「修改招呼语提示词」在弹窗里编辑，保存立即生效，可一键恢复默认

⑥ 发送

指标卡实时刷新：已勾选 / 已填进输入框 / 已发出 / 跳过失败

放到输入框（默认）：逐个把招呼语填进 BOSS 输入框就停下，你在浏览器里过目、亲自点发送；发完自动进下一个

注意：填进输入框后请尽快手动点发送：这一步只是把文字放进输入框、还没发出去。若此时脚本再次运行、或 BOSS 页面被刷新，输入框里的招呼语就会消失，需要重新生成 / 重填

直接发送：填好即自动发送、连着跑，必须你本人在面板上亲自确认才会启动；agent 无权替你点

没有"全自动无人值守"选项：机器永远不能替你绕过确认，这是工具的核心设计原则

发送按当日剩余额度自动截断（每日上限默认 60）；遇到安全验证会停下等你人工完成，然后自动继续；「换职位沟通」之类的确认弹窗自动处理；全程随时可「停止」

⑦ 记录

四项统计各含总量与今日：爬取 / 发送 / 放入输入框 / 下架（下架 = 爬过的岗位已失效或被撤）

明细：时间 · 岗位 · 公司 · 状态（已填入到输入框 / 已发送 / 已下架），保留最近 120 条；往下滚时表头会吸顶跟着走

agent 也能读到这些数据（含勾选状态），你和它看到的是同一份事实

⑧ 设置

限额：一次最多爬 / 一天最多爬 / 一天最多发；出厂默认是 10 / 80 / 60，都能按你的情况调

节奏：发送与爬取的间隔（大多数时候几秒、偶尔慢一点的占比与时长）、沟通前在 JD 页面停留、爬取时停留与滚轮滑动

改动后点「保存设置」生效；没保存就切页会提示，选「不保存」则还原；本页刷新也不会丢未保存的改动；「撤销改动」「恢复默认设置」随时可用

顶栏状态

空闲：没任务，可以开始；运行中：正在爬取或发送；已暂停 / 正在停止：任务处理中；出错了：任务异常，去 logs/ 看最新日志

让 agent 帮你干

把项目根目录的 AGENTS.md 交给你的 AI 助手，它就能按手册通过本地接口操作整个工具

推荐交给它：智能二筛（搜公司背景 + 评匹配度 + 自动勾选）、逐条写定制招呼语、补全知识库、按你的情况调爬取数量与节奏

它的每一步操作面板上实时可见，随时可以「停止」；勾选和招呼语不满意，直接自己改
