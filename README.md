# Job Search Workbench

> 求职助手 —— 纯本地运行的 BOSS直聘 海投工作台

一个本地跑的 BOSS直聘 求职工作台：能批量爬取岗位信息；招呼语可以自己填，也可以让 agent 根据你填的经历知识库和岗位 JD 来定制；发送时你可以选择「批量填进输入框、自己确认后再发」，也可以「直接批量发送」。

## 环境要求

- **仅支持 Windows**（关闭浏览器、清理残留进程等用了 PowerShell，macOS / Linux 未适配）
- **Node.js 18+**（开发环境实测 v24）
- **本机已装 Google Chrome**：工具只驱动你本机的 Chrome，不额外下载浏览器内核
- 联网环境 + 一个 BOSS直聘 账号（首次扫码登录一次，之后复用本地浏览器配置目录）

## 安装与启动

```bash
git clone https://github.com/yugru7/jobbench.git
```

下载后进目录，**双击 `启动.bat`** 即可（首次会自动装依赖，之后直接启动）；也可 `node server.js --open`。面板地址 **http://127.0.0.1:7788**，关掉窗口即停止服务（正在跑的任务一并结束）。

## 第一次使用

1. **岗位初筛**：选省份 / 城市，填关键词，选单次数量
2. **获取岗位**：点开始 → 弹出独立浏览器窗口，**首次需扫码登录 BOSS**（只登一次，登录窗口别关）
3. **候选池**：按类型 / 活跃度 / 双休 / 日薪 / 公司规模 / 行业筛选，勾选要投的岗位
4. **知识库**：填你**真实的**经历与技能（agent 写招呼语的原料，只写真做过的事）
5. 把 [`AGENTS.md`](AGENTS.md) 交给你的 agent：读知识库、评匹配度、勾选、写招呼语；也可以纯手动
6. **编辑招呼语**：逐条过目、修改
7. **发送**：默认「放到输入框」——机器只填不点发送，你自己在浏览器点；「直接发送」会真的发出，须你在弹窗亲自确认

## 数据都在哪（隐私）

全部落在项目目录，无任何远端存储：

| 文件 | 内容 |
|---|---|
| `config.json` | 运行配置（城市 / 关键词 / 限额 / 间隔参数） |
| `knowledge.json` | 知识库（身份 / 技能 / 经历） |
| `prompts/greeting.md` | 招呼语生成规则 |
| `logs/last-collect.json` | 候选池（岗位 + JD + 活跃度 + 招呼语 + 发送标记） |
| `logs/` 其余 | 统计、打招呼明细、黑名单 |

信息的对外出口只有两处：**发给 HR 的招呼语**和**你与 agent 的对话**。`knowledge.json`、`logs/`、`.chrome-profile/` 都在 `.gitignore` 里，不会被提交。

## 风险提示

用自动化工具操作账号**仍有封号风险**。工具做了拟人化节奏（随机间隔、点击与阅读停顿、随机预热站点）、每日发送 / 爬取上限、失败自动进黑名单、接口只受理本机请求等降概率措施，但**不能消除**。介意的话请不要使用。

本项目仅供学习与技术研究，**与 BOSS直聘 无任何关联，非官方工具**；请遵守 BOSS直聘用户协议与所在地法律，不要用于大规模商业获客或骚扰。招呼语会发给真人 HR，内容务必真实 —— 面试会被追问。

## 常见问题

- **面板打不开** → 服务没起：双击 `启动.bat` 或 `node server.js`
- **报找不到 node / Chrome** → 装 Node.js 18+ / Google Chrome
- **被弹安全验证** → 在弹出的窗口里手动过滑块，过完任务自动继续
- **浏览器被占用 / 上次有残留** → 面板顶栏点「关闭浏览器」，等几秒再重试
- **改了 `server.js` 不生效** → 服务需重启（只改前端文件的话刷新面板即可）

## 卸载 / 清理

关掉 `启动.bat` 窗口即停止服务（任务一并停止）；配置、知识库、候选池、记录都在项目目录，直接删整个目录即可（`profileDir` 若改到别处需手动删）。想留底先备份 `knowledge.json` 和 `logs/`。
